06

Notes

These mockups are static HTML—they don't represent live behavior. Their purpose is to make the layout, density, and visual language concrete enough to critique. The styling extends DnaOneCalc's warm beige palette (continuity for users moving between products).

Each mockup is grounded in specific UX requirements sections (cross-referenced in comments inside each file). The requirements doc is the source of truth for what each region must contain; the mockups show one defensible visual interpretation.
